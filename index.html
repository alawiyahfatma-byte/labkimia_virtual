Informasi Spesifikasi & SOP

Fungsi Utama:

Digunakan untuk menampung larutan, mereaksikan zat kimia, dan sebagai wadah titrat saat titrasi.

Material & Ketahanan:

Kaca Borosilikat (Pyrex) tahan panas hingga 500°C dan tahan goncangan termal.

Kesalahan Umum (Common Mistakes):

Bukan alat ukur presisi! Garis skala pada Erlenmeyer hanya bersifat estimasi perkiraan (toleransi ±5%).

Cara Penggunaan yang Benar:

Pegang leher labu dengan tiga jari saat mengaduk (swirling) larutan dengan gerakan memutar searah jarum jam.

Simbol Bahaya Kimia Global (GHS Hazard Pictograms)

Pelajari 9 piktogram keselamatan kimia internasional, arti bahaya, contoh bahan kimia nyata, dan SOP pertolongan pertama.

10 Aturan Emas Keselamatan Bekerja di Laboratorium Kimia

Pedoman standar laboratorium pendidikan menurut standar Kemenkes & OSHA

1
Selalu Kenakan APD Lengkap

Jas lab, kacamata pengaman, sarung tangan, dan sepatu tertutup adalah harga mati sebelum masuk.

2
Dilarang Makan, Minum, atau Mencicipi

Zat kimia dapat mengkontaminasi makanan atau tertelan tanpa sengaja melalui kontak tangan.

3
Teknik Membaui Zat yang Benar (Wafting)

Jangan pernah menghirup langsung mulut tabung. Kibaskan uap menggunakan telapak tangan ke arah hidung.

4
Pengenceran Asam Pekat (AA - Asam ke Air)

Selalu tuangkan Asam ke dalam Air secara perlahan lewat dinding gelas, BUKAN sebaliknya untuk mencegah letupan eksoterm.

5
Bekerja di Lemari Asam (Fume Hood)

Reaksi yang menghasilkan gas beracun (misal: NO2, Cl2, NH3 pekat) wajib dilakukan di lemari asam.

6
Membaca Label Botol Kimia Dua Kali

Pastikan nama rumus kimia dan konsentrasi sesuai sebelum menuangkan reagen.

7
Arah Pemanasan Tabung Reaksi

Arahkan mulut tabung reaksi ke tempat kosong yang tidak ada orang saat dipanaskan di atas api bunsen.

8
Penanganan Tumpahan Kimia

Segera bilas dengan air mengalir (safety shower / eyewash) minimal 15 menit jika terkena asam/basa.

9
Pembuangan Limbah Kimia Terpisah

Jangan membuang pelarut organik atau logam berat ke wastafel. Gunakan jerigen limbah B3 khusus.

10
Mengetahui Lokasi Alat Darurat

Hafalkan posisi APAR (Alat Pemadam Api Ringan), Kotak P3K, Selimut Api, dan Jalur Evakuasi.

Insiden Letupan & Tumpahan Larutan pada Prosedur Pengenceran Asam Sulfat Pekat (H₂SO₄ 98%)

Di Laboratorium Kimia SMA, seorang praktikan hendak mengencerkan 10 mL Asam Sulfat pekat (H₂SO₄ 98%). Karena terburu-buru mengejar waktu praktikum:

  • Praktikan tidak mengenakan sarung tangan nitril maupun kacamata pengaman (goggles).
  • Mengukur volume 10 mL asam pekat menggunakan gelas beker besar (beaker glass 250 mL) dan bukan pipet ukur presisi.
  • Menuangkan air langsung ke dalam gelas beker berisi asam pekat secara mendadak.

Dampak Insiden: Terjadi letupan mendidih seketika akibat pelepasan kalor hidrasi yang sangat besar (eksotermik), uap asam pekat membubung, dan percikan asam sulfat menyembur membasahi meja serta jari praktikan!

function doGet(e) {
  return ContentService.createTextOutput(JSON.stringify({
    status: 'success',
    message: 'Backend Google Apps Script ChemLab 3D Aktif & Terhubung!',
    timestamp: new Date().toISOString()
  })).setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    var rawData = e.postData.contents;
    var data = JSON.parse(rawData);
    var ss = SpreadsheetApp.getActiveSpreadsheet();

    // 1. Aksi: Simpan Nilai Siswa (Lab + Kuis) atau Bulk Sinkronisasi
    if (data.action === 'saveQuiz' || data.action === 'syncAll') {
      var sheetScores = getOrCreateSheet(ss, 'Rekap_Nilai_Siswa', [
        'Timestamp', 'Nama Siswa', 'NISN', 'Kelas', 'Sekolah', 'Nilai Lab Praktikum', 'Nilai Kuis Teori', 'Nilai Akhir Kumulatif', 'Predikat', 'Status Kelulusan'
      ]);
      
      if (data.action === 'syncAll' && data.submissions) {
        data.submissions.forEach(function(s) {
          sheetScores.appendRow([
            s.timestamp || new Date().toLocaleString('id-ID'),
            s.name, s.nisn, s.className, s.school, s.labScore || 0, s.quizScore || 0, s.finalScore || 0, s.predicate, s.status
          ]);
        });
      } else {
        sheetScores.appendRow([
          data.timestamp || new Date().toLocaleString('id-ID'),
          data.name, data.nisn, data.className, data.school, data.labScore || 0, data.quizScore || 0, data.finalScore || 0, data.predicate, data.status
        ]);
      }
    }

    // 2. Aksi: Simpan Log Aktivitas Praktikum Lab Real-time
    if (data.action === 'saveLabActivity') {
      var sheetLab = getOrCreateSheet(ss, 'Log_Aktivitas_Lab', [
        'Timestamp', 'Nama Siswa', 'NISN', 'Kelas', 'Sekolah', 'Aktivitas Lab', 'Skor Aktivitas', 'Detail Parameter', 'Total Nilai Lab', 'Nilai Akhir'
      ]);
      sheetLab.appendRow([
        data.timestamp || new Date().toLocaleString('id-ID'),
        data.name, data.nisn, data.className, data.school, data.activityName, data.activityScore || 0, data.activityDetail || '', data.labScore || 0, data.finalScore || 0
      ]);
    }

    // 2. Aksi: Simpan LKPD PBL Digital
    if (data.action === 'saveLKPD') {
      var sheetLKPD = getOrCreateSheet(ss, 'Data_LKPD_PBL', [
        'Timestamp', 'Nama Siswa', 'Kelas', 'Identifikasi Masalah (F1)', 'Hipotesis (F2)', 'Analisis & Kesimpulan (F3)'
      ]);
      sheetLKPD.appendRow([
        new Date().toLocaleString('id-ID'),
        data.name, data.className, data.q1, data.q2, data.q3
      ]);
    }

    // 3. Aksi: Simpan Jurnal Refleksi Siswa
    if (data.action === 'saveReflection') {
      var sheetRef = getOrCreateSheet(ss, 'Refleksi_Siswa', [
        'Timestamp', 'Nama Siswa', 'Kelas', 'Mood', 'Rating Bintang', '3 Hal Dipelajari', '2 Tantangan', '1 Komitmen'
      ]);
      sheetRef.appendRow([
        new Date().toLocaleString('id-ID'),
        data.name, data.className, data.mood, data.rating, data.q1, data.q2, data.q3
      ]);
    }

    return ContentService.createTextOutput(JSON.stringify({
      status: 'success',
      message: 'Data berhasil disinkronkan ke Google Spreadsheet!'
    })).setMimeType(ContentService.MimeType.JSON);

  } catch(error) {
    return ContentService.createTextOutput(JSON.stringify({
      status: 'error',
      message: error.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

function getOrCreateSheet(ss, name, headers) {
  var sheet = ss.getSheetByName(name);
  if (!sheet) {
    sheet = ss.insertSheet(name);
    sheet.appendRow(headers);
    sheet.getRange(1, 1, 1, headers.length)
      .setFontWeight('bold')
      .setBackground('#1e3a8a')
      .setFontColor('#ffffff');
    sheet.setFrozenRows(1);
  }
  return sheet;
}
